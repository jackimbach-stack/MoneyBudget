Money Splitter PWA

Files:
- index.html
- manifest.webmanifest
- sw.js
- icons/

How to install on iPhone:
1. Put this folder on any HTTPS web host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the site in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Open it from the new home-screen icon.

Balances and transaction history are stored locally on the device/browser using localStorage.
